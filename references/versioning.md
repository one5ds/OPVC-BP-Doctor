# 病历版本对照规则

同一项目再次诊断时，必须做版本对照，且旧病历保留不覆盖。

## 1. 定位旧病历

在项目约定的病历输出目录查找：
```
BP病历_[项目简称]_*_v*.md
```
匹配「项目简称」一致的所有病历，取版本号 `v` 最大的一份作为「上一版」。项目简称不同则视为新项目，不做对照。

## 2. 新病历命名与版本号

新病历文件名：`BP病历_[项目简称]_[YYYYMMDD]_v[序号].md`

- 若上一版存在，序号 = 上一版序号 + 1；
- 若不存在，序号 = 1。

旧病历文件**绝不覆盖、绝不删除**。同一天多次诊断也递增版本号，不复用文件名。

## 3. 新增「版本对照」章节

新病历在模板结构基础上，于「外部核验标记」之前插入：

```markdown
## 版本对照（v[旧] → v[新]）
| 维度 | 旧分 | 新分 | 变化 | 上一版核心问题是否解决 |
|---|---|---|---|---|
[逐维度填写：变化写 +N / −N / 0；是否解决写 是 / 部分 / 否 / 新增]

总分：旧 → 新（变化 ±N）
等级：旧 → 新
**仍未解决的高优先级问题：**
1. …
```

- 「上一版核心问题是否解决」须对照上一版病历「药方摘要」与「核心问题」逐条判断，不得含糊。
- 「仍未解决的高优先级问题」列出上一版优先级清单中，新版本仍未达标的项目。

## 4. 交付一致性

HTML 报告文件名仍为 `BP诊断报告_[项目简称]_[YYYYMMDD].html`（不带版本号，每版覆盖为最新诊断），但病历按版本累积，形成可追溯的修改对照链。报告与病历的核心分数、等级、问题清单必须一致。
